# java-lotto-precourse

### 입력 기능
- [ ] 로또 구입 금액 입력받기
  - [ ] 1,000원 단위로 입력 검증
  - [ ] 1,000원으로 나누어떨어지지 않으면 예외 처리
- [ ] 당첨 번호 입력받기
  - [ ] 쉼표(,)로 구분된 6개 숫자
  - [ ] 1~45 범위 검증
  - [ ] 중복 검증
- [ ] 보너스 번호 입력받기
  - [ ] 1~45 범위 검증
  - [ ] 당첨 번호와 중복되지 않는지 검증

### 로또 발행 기능
- [ ] 구입 금액으로 로또 개수 계산
- [ ] 랜덤으로 로또 번호 생성
  - [ ] 1~45 범위에서 중복되지 않는 6개 숫자
  - [ ] Randoms.pickUniqueNumbersInRange() 사용
- [ ] 생성된 로또 번호를 오름차순으로 정렬

### 당첨 확인 기능
- [ ] 구매한 로또와 당첨 번호 비교
- [ ] 일치하는 번호 개수 계산
- [ ] 보너스 번호 일치 여부 확인
- [ ] 당첨 등수 계산

### 출력 기능
- [ ] 구매한 로또 개수 및 번호 출력
- [ ] 당첨 통계 출력
  - [ ] 각 등수별 당첨 개수
- [ ] 수익률 계산 및 출력
  - [ ] 소수점 둘째 자리에서 반올림

### 도메인 객체
- [ ] Lotto 클래스
  - [ ] 6개 숫자 검증
  - [ ] 추가 기능 구현
- [ ] LottoMachine (로또 발행기)
- [ ] WinningLotto (당첨 번호)
- [ ] LottoResult (당첨 결과)
